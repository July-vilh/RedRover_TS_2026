\## 🕒 00:03:51 — Что такое TypeScript (TS)?

> \*\*Ключевая мысль:\*\* TypeScript — это «JavaScript с проверкой ошибок».



\*   \*\*Статическая типизация:\*\* Ошибки подсвечиваются прямо во время написания кода, а не когда программа «упала» у пользователя.

\*   \*\*Транспиляция:\*\* Браузеры не понимают `.ts` файлы. Специальная программа-переводчик превращает наш TS-код в обычный JS.



\---



\## 🕒 00:13:22 — Роль автоматизации

\*   \*\*Регрессия:\*\* Автоматизация нужна, чтобы быстро проверять, что старые функции работают корректно после внесения новых изменений.

\*   \*\*Точность:\*\* В программировании важен каждый пробел и точка с запятой. Ошибка в одном символе — программа не работает.

\## 🕒 00:37:37 — Настройка окружения (Node.js)

\*\*Node.js\*\* — это движок, который позволяет запускать код на вашем компьютере, а не только в браузере.



\*   \*\*Версия для курса:\*\* `24.19.0` (LTS).

\*   \*\*Проверка установки (через Терминал/CMD):\*\*

&#x20;   \*   `node -v` — версия ноды.

&#x20;   \*   `npm -v` — версия пакетного менеджера (ставится вместе с нодой).



⚠️ \*\*Для пользователей Mac:\*\* Если раньше ставили Node через `brew`, лучше его удалить (`brew uninstall node`), чтобы избежать конфликтов с официальным установщиком.

\## 🕒 01:09:13 — Инициализация проекта

Команды в терминале внутри папки проекта:

1\.  `npm init -y` — создает `package.json` (паспорт вашего проекта).

2\.  `npm install typescript tsx` — устанавливает сам язык и инструмент для его запуска.



> \*\*Node\_modules:\*\* В этой папке лежат библиотеки. Её никогда не трогаем руками и не меняем там файлы.



\---



\## 🕒 01:21:40 — Конфигурация запуска TS

Чтобы кнопка "Play" в VS Code понимала TypeScript, в папке `.vscode` создаем файл `settings.json` и добавляем:

```json

{

&#x20;   "code-runner.executorMap": {

&#x20;       "typescript": "npx tsx"

&#x20;   }

}

```

\## 🕒 01:34:40 — Культура написания кода (Clean Code)

1\.  \*\*Читаемость:\*\* Код пишется для людей. Если вы вернетесь к нему через 3 месяца, вы должны его понять.

2\.  \*\*Стиль:\*\*

&#x20;   \*   Отступы: \*\*4 пробела\*\*.

&#x20;   \*   Имена файлов: \*\*CamelCase\*\* (например, `MyFirstTest.ts`).

&#x20;   \*   Завершение строк: Точка с запятой `;`.

3\.  \*\*Комментарии:\*\* Используйте `//` для одной строки или `Ctrl + /` как горячую клавишу.
