# TypeScript для начинающих: переменные, типы и операторы

> Этот конспект основан на лекции о переменных и операторах и дополнен пояснениями, которые помогают понять тему с нуля.
>
> \*\*Обозначения:\*\*
> - \*\*По лекции\*\* — материал, который разбирался преподавателем.
> - \*\*Дополнение\*\* — пояснение, уточнение или важная деталь, которую я добавил для понимания темы.
> - \*\*Важно\*\* — место, где формулировку из лекции полезно уточнить, чтобы не закрепить неверное правило.

\---

# 1\. Сначала общая картина: что происходит с TypeScript-кодом

Мы пишем:

```ts
const userName: string = "Anna";
console.log(userName);
```

Файл сохраняется как:

```text
example.ts
```

Но в конечном счёте выполняется JavaScript.

Упрощённо процесс выглядит так:

```text
TypeScript (.ts)
      ↓
проверка типов
      ↓
преобразование в JavaScript
      ↓
JavaScript выполняется Node.js или браузером
```

В учебном проекте используется `tsx`, поэтому отдельный `.js`-файл обычно не появляется:

```bash
npx tsx example.ts
```

`tsx` преобразует TypeScript и сразу запускает результат.

## Почему вообще нужен TypeScript

JavaScript позволяет сделать, например, такое:

```js
let age = 25;
age = "twenty five";
```

Для JavaScript это допустимо.

TypeScript позволяет заранее описать ожидание:

```ts
let age: number = 25;
age = "twenty five"; // ошибка TypeScript
```

То есть TypeScript старается найти часть ошибок **до запуска программы**.

> \*\*Главная идея:\*\* TypeScript не заменяет JavaScript. Он добавляет над JavaScript систему типов и инструменты статической проверки.

# 2\. Что такое переменная

**По лекции:** переменная — это именованное место, в котором мы храним данные, чтобы затем использовать их в коде.

Например:

```ts
const firstName: string = "John";
```

Здесь мы сохранили строку `"John"` под именем `firstName`.

Позже можем использовать переменную:

```ts
console.log(firstName);
```

Вместо того чтобы много раз писать:

```ts
console.log("John");
```

\---

# 3\. Из чего состоит объявление переменной

Рассмотрим:

```ts
const fullName: string = "John Smith";
```

|Часть|Что означает|
|-|-|
|`const`|способ объявления переменной|
|`fullName`|имя переменной|
|`:`|отделяет имя от явного указания типа|
|`string`|тип данных|
|`=`|оператор присваивания|
|`"John Smith"`|значение|
|`;`|конец инструкции|

Полезно научиться читать код словами:

> «Создай константную переменную `fullName` типа `string` и присвой ей значение `"John Smith"`».

\---

# 4\. Объявление, инициализация и присваивание — это не одно и то же

Эти термины легко спутать.

## Объявление — declaration

Мы создаём переменную:

```ts
let firstName: string;
```

Переменная существует, но собственного значения мы ещё не присвоили.

## Инициализация — initialization

Первое присваивание значения при создании:

```ts
let firstName: string = "John";
```

## Присваивание — assignment

Записываем значение в уже существующую переменную:

```ts
firstName = "Anna";
```

Оператор:

```text
=
```

означает **присваивание**, а не математическое «равно».

\---

# 5\. `const` и `let`

Это два основных способа объявлять переменные в современном JavaScript/TypeScript.

## `const`

Используем, если переменной не потребуется присваивать другое значение:

```ts
const country: string = "Georgia";
```

Так нельзя:

```ts
country = "Spain"; // ошибка
```

## `let`

Используем, если значение должно изменяться:

```ts
let score: number = 10;

score = 15;
score = 20;
```

## Хорошее правило

Начинай с `const`.

Используй `let` только тогда, когда действительно собираешься менять значение.

```ts
const userName = "Anna";
let attempts = 0;
```

\---

# 6\. Важное уточнение про `const`

`const` означает:

> переменной нельзя присвоить \*\*другое значение\*\*.

Но это не всегда означает, что само содержимое значения абсолютно неизменяемо.

Например:

```ts
const user = {
    name: "Anna"
};

user.name = "Maria"; // допустимо
```

Но:

```ts
user = { name: "Maria" }; // ошибка
```

Почему?

Потому что в первом случае переменная `user` всё ещё ссылается на тот же объект. Мы изменили свойство объекта.

Во втором случае пытаемся присвоить `user` другой объект.

Для начала достаточно запомнить:

> \*\*`const` запрещает повторное присваивание самой переменной.\*\*

К объектам и ссылочным типам мы вернёмся позже.

\---

# 7\. Что такое `var`

В старом JavaScript часто встречается:

```js
var name = "John";
```

**По лекции:** в новом коде курса `var` использовать не будем, но нужно понимать его при чтении старого кода.

Это разумное правило.

`var` отличается от `let` и `const` особенностями области видимости и hoisting. Сейчас эти детали лучше не заучивать.

Для нового кода:

```text
const → значение не переназначаем
let   → значение будем менять
```

\---

# 8\. Как называть переменные

Имя должно помогать понять смысл данных.

Плохо:

```ts
const a = "John Smith";
const x = 25;
```

Лучше:

```ts
const fullName = "John Smith";
const userAge = 25;
```

## `camelCase`

Для обычных переменных в JavaScript/TypeScript обычно используется `camelCase`:

```ts
firstName
lastName
userAge
totalPrice
isLoggedIn
```

Первая буква маленькая, каждое следующее слово начинается с большой буквы:

```text
user + name → userName
total + order + price → totalOrderPrice
```

\---

# 9\. Какие символы разрешены в именах

Для новичка можно пользоваться простым правилом:

* английские буквы;
* цифры — но не первой;
* `\_`;
* `$`.

Например:

```ts
user1
firstName
\_privateValue
$price
```

Нельзя:

```ts
1user
```

Нельзя использовать зарезервированные слова языка:

```ts
const const = 5; // нельзя
```

## Важно

В лекции правило было упрощено до «буквы и цифры, первый символ — буква».

Технически JavaScript допускает также `\_`, `$` и некоторые Unicode-символы.

Но для учебного и рабочего кода хорошая привычка — обычные понятные английские имена:

```ts
userName
orderPrice
isActive
```

\---

# 10\. Точка с запятой `;`

В курсе используется:

```ts
const name = "John";
console.log(name);
```

Это нормальная и распространённая конвенция.

## Важно

JavaScript/TypeScript умеет автоматически вставлять точки с запятой во многих местах, поэтому такой код часто тоже работает:

```ts
const name = "John"
console.log(name)
```

Но в твоём учебном проекте принято писать `;`, поэтому придерживайся этого стиля.

> Здесь речь не о том, что без `;` код всегда неправильный, а о принятой конвенции.

# 11\. Что такое тип данных

Тип говорит, **какого рода значение находится в переменной**.

Например:

```ts
const userName: string = "Anna";
const age: number = 18;
const isStudent: boolean = true;
```

Типы:

```text
string   → текст
number   → числа
boolean  → true / false
```

\---

# 12\. `string`

Строка — текстовое значение.

```ts
const city: string = "Tbilisi";
```

Строки можно записывать тремя способами:

```ts
"Hello"
'Hello'
`Hello`
```

В учебном проекте можно придерживаться двойных кавычек:

```ts
const greeting = "Hello";
```

Backticks:

```ts
`Hello`
```

особенно важны для template literals, которые будут изучаться позже:

```ts
const name = "Anna";
console.log(`Hello, ${name}!`);
```

\---

# 13\. `number`

В JavaScript/TypeScript основной числовой тип:

```ts
number
```

Например:

```ts
const age: number = 18;
const price: number = 19.99;
const temperature: number = -5;
```

И целые числа, и обычные десятичные числа относятся к `number`.

\---

# 14\. `boolean`

Boolean имеет только два значения:

```ts
true
false
```

Например:

```ts
const isLoggedIn: boolean = true;
const hasAccess: boolean = false;
```

Для boolean-переменных удобно давать имена, которые читаются как вопрос:

```ts
isActive
hasPermission
canEdit
shouldRetry
```

Тогда код легче читать:

```ts
if (hasPermission) {
    // ...
}
```

\---

# 15\. `null`

`null` обычно означает:

> значение намеренно отсутствует.

Например:

```ts
let selectedUser: string | null = null;
```

Мы явно говорим:

> сейчас пользователя нет.

\---

# 16\. `undefined`

`undefined` обычно означает:

> значение не было определено / присвоено.

Например:

```ts
let userName: string | undefined;

console.log(userName);
```

До присваивания значение будет `undefined`.

\---

# 17\. `null` и `undefined`: простая ментальная модель

Для начала можно мыслить так:

```text
null       → «значения намеренно нет»
undefined  → «значение пока не определено / не найдено»
```

Реальное поведение языка немного сложнее, но эта модель хорошо подходит новичку.

\---

# 18\. Type annotation — явное указание типа

Можно написать:

```ts
const name: string = "Anna";
```

Часть:

```ts
: string
```

называется **type annotation** — явная аннотация типа.

\---

# 19\. Type inference — вывод типа

Очень важное дополнение.

TypeScript часто способен сам определить тип:

```ts
const name = "Anna";
```

Он понимает:

```text
name → string
```

А здесь:

```ts
const age = 18;
```

понимает:

```text
age → number
```

Поэтому совершенно нормально писать:

```ts
const userName = "Anna";
const userAge = 18;
const isStudent = true;
```

а не:

```ts
const userName: string = "Anna";
const userAge: number = 18;
const isStudent: boolean = true;
```

## Важно

Формулировку «в TypeScript при создании каждой переменной мы обязаны написать тип» нельзя воспринимать буквально.

Правильнее:

> Каждая переменная в TypeScript имеет тип, но его не обязательно всегда писать вручную — TypeScript часто выводит его автоматически.

\---

# 20\. Почему TypeScript ругается ещё до запуска

Например:

```ts
let age: number = 18;

age = "eighteen";
```

Редактор может сразу подчеркнуть строку.

Это результат **статической проверки типов**.

`static` здесь означает:

> анализ выполняется до реального исполнения программы.

В этом одна из главных ценностей TypeScript.

\---

# 21\. Повторное объявление переменной

Так делать нельзя в одной области видимости:

```ts
let value = 10;
let value = 20;
```

Переменная с таким именем уже объявлена.

Но изменить значение `let` можно:

```ts
let value = 10;
value = 20;
```

Обрати внимание:

```ts
let value = 10; // объявление
value = 20;     // новое присваивание
```

Во второй строке `let` уже не пишется.

\---

# 22\. `typeof`

`typeof` позволяет узнать тип значения во время выполнения JavaScript.

```ts
const age = 18;

console.log(typeof age);
```

Результат:

```text
number
```

Ещё примеры:

```ts
typeof "Hello"  // "string"
typeof 10       // "number"
typeof true     // "boolean"
typeof undefined // "undefined"
```

Можно встретить:

```ts
typeof value
```

и:

```ts
typeof(value)
```

Оба варианта работают.

Обычно пишут:

```ts
typeof value
```

\---

# 23\. Важная странность `typeof`

JavaScript содержит исторические особенности.

Например:

```ts
typeof null
```

даёт:

```text
"object"
```

Хотя `null` не является обычным объектом в том смысле, в котором новичок ожидает.

Это старое поведение JavaScript.

Пока достаточно просто помнить:

```ts
typeof null === "object"
```

как исключение.

\---

# 24\. Преобразование типов

Иногда значение нужно преобразовать из одного типа в другой.

Это называется **type conversion**.

\---

# 25\. Число → строка

```ts
const age: number = 18;
const ageAsText: string = String(age);
```

Теперь:

```ts
typeof age         // "number"
typeof ageAsText   // "string"
```

Важно: исходная переменная `age` не изменилась.

Мы получили **новое значение другого типа**.

\---

# 26\. Строка → число

```ts
const ageText = "18";
const age = Number(ageText);
```

Получаем число:

```ts
18
```

\---

# 27\. Что будет с `Number("hello")`

```ts
const result = Number("hello");
```

JavaScript не может получить осмысленное число.

Результат:

```ts
NaN
```

`NaN` означает:

```text
Not-a-Number
```

Но здесь есть странность:

```ts
typeof NaN
```

возвращает:

```text
"number"
```

Это часть поведения JavaScript.

Для проверки лучше использовать:

```ts
Number.isNaN(value);
```

Например:

```ts
const result = Number("hello");

console.log(Number.isNaN(result)); // true
```

# 28\. Арифметические операторы

Основные:

|Оператор|Действие|
|-|-|
|`+`|сложение|
|`-`|вычитание|
|`\*`|умножение|
|`/`|деление|
|`%`|остаток от деления|
|`\*\*`|возведение в степень|

Примеры:

```ts
10 + 5;  // 15
10 - 5;  // 5
10 \* 5;  // 50
10 / 5;  // 2
10 % 3;  // 1
2 \*\* 3;  // 8
```

\---

# 29\. Особенность оператора `+`

`+` используется не только для чисел, но и для строк.

## Число + число

```ts
10 + 5
```

Результат:

```text
15
```

## Строка + строка

```ts
"Hello" + "World"
```

Результат:

```text
"HelloWorld"
```

Это называется **конкатенация** — соединение строк.

Чтобы получить пробел:

```ts
"Hello" + " " + "World"
```

\---

# 30\. Число + строка

Вот здесь начинается одна из классических ловушек JavaScript:

```ts
10 + "5"
```

Результат:

```text
"105"
```

Почему?

Поскольку один из операндов — строка, JavaScript использует `+` как конкатенацию.

То есть:

```text
10 → "10"
"10" + "5" → "105"
```

Это одна из причин, почему важно понимать типы данных.

\---

# 31\. Другие арифметические операции со строками

JavaScript иногда пытается автоматически преобразовывать строку в число:

```js
"10" - 5 // 5
"10" \* 2 // 20
"10" / 2 // 5
```

Но:

```js
"Hello" - 5 // NaN
```

## Важно для TypeScript

TypeScript часто не позволит написать потенциально проблемную операцию ещё на этапе проверки типов.

Поэтому TypeScript помогает избегать части неочевидного поведения JavaScript.

\---

# 32\. Оператор `%` — остаток от деления

Очень полезный оператор:

```ts
10 % 3
```

`10 / 3`:

```text
3 целых, остаток 1
```

Поэтому:

```ts
10 % 3 // 1
```

Другие примеры:

```ts
9 % 3  // 0
14 % 5 // 4
```

\---

# 33\. Проверка чётного числа

У любого чётного числа при делении на 2 остаток равен 0:

```ts
number % 2 === 0
```

Например:

```ts
const value = 8;

console.log(value % 2 === 0); // true
```

Для 7:

```ts
7 % 2 // 1
```

\---

# 34\. Проверка кратности

Например, хотим узнать, делится ли число на 5 без остатка:

```ts
value % 5 === 0
```

```ts
const value = 20;

console.log(value % 5 === 0); // true
```

\---

# 35\. Приоритет арифметических операций

Как в математике:

```ts
2 + 3 \* 4
```

Сначала:

```text
3 × 4 = 12
```

затем:

```text
2 + 12 = 14
```

Результат:

```text
14
```

Если хотим изменить порядок:

```ts
(2 + 3) \* 4
```

получаем:

```text
20
```

## Хорошая привычка

Если выражение становится трудно читать, используй скобки даже тогда, когда знаешь приоритет операторов.

Код читают люди, а не только компьютер.

\---

# 36\. Инкремент `++`

Инкремент увеличивает значение на 1.

```ts
let counter = 0;

counter++;
```

Теперь:

```text
counter === 1
```

Это сокращённый способ написать:

```ts
counter = counter + 1;
```

\---

# 37\. Декремент `--`

Уменьшает значение на 1:

```ts
let counter = 5;

counter--;
```

После этого:

```text
counter === 4
```

\---

# 38\. `value++` и `++value`

Эти варианты похожи, но не полностью одинаковы.

## Постфиксный инкремент

```ts
value++
```

Сначала выражение возвращает старое значение, затем увеличивает переменную.

```ts
let value = 5;
const result = value++;

console.log(result); // 5
console.log(value);  // 6
```

## Префиксный инкремент

```ts
++value
```

Сначала значение увеличивается, затем возвращается:

```ts
let value = 5;
const result = ++value;

console.log(result); // 6
console.log(value);  // 6
```

Если просто написать:

```ts
value++;
```

отдельной строкой, разница обычно не имеет значения.

Она становится важной, когда `++` является частью большего выражения.

\---

# 39\. Составные операторы присваивания

Вместо:

```ts
score = score + 5;
```

можно написать:

```ts
score += 5;
```

Другие варианты:

```ts
score -= 5;
score \*= 2;
score /= 2;
score %= 3;
```

То есть:

```ts
x += y;
```

примерно соответствует:

```ts
x = x + y;
```

# 40\. Операторы сравнения

Сравнение возвращает `boolean`:

```text
true
```

или:

```text
false
```

Основные операторы:

|Оператор|Значение|
|-|-|
|`===`|строго равно|
|`!==`|строго не равно|
|`>`|больше|
|`<`|меньше|
|`>=`|больше или равно|
|`<=`|меньше или равно|

Пример:

```ts
const age = 18;

age >= 18 // true
age < 18  // false
```

\---

# 41\. Главное: `=` и `===` — совершенно разные вещи

## `=`

Присваивание:

```ts
let age = 18;
```

Читаем:

> присвоить `age` значение `18`.

## `===`

Сравнение:

```ts
age === 18
```

Читаем:

> `age` строго равно `18`?

Результат:

```text
true
```

или:

```text
false
```

Это одна из самых важных разниц, которую нужно закрепить.

\---

# 42\. `==` и `===`

JavaScript имеет два вида сравнения равенства.

## Нестрогое — `==`

Может преобразовывать типы:

```js
5 == "5" // true
```

JavaScript пытается привести значения к совместимым типам.

## Строгое — `===`

Типы тоже должны совпадать:

```js
5 === "5" // false
```

Потому что:

```text
5   → number
"5" → string
```

## Практическое правило

В современном JavaScript/TypeScript почти всегда используй:

```ts
===
!== 
```

а не:

```ts
==
!=
```

Это делает поведение более предсказуемым.

\---

# 43\. Логические операторы

Используются, когда нужно объединять условия.

Основные:

```text
\&\& → AND
|| → OR
!  → NOT
```

\---

# 44\. AND — `\&\&`

Выражение истинно, только если **оба** условия истинны.

```ts
true \&\& true   // true
true \&\& false  // false
false \&\& true  // false
false \&\& false // false
```

Пример:

```ts
const age = 20;
const hasTicket = true;

const canEnter = age >= 18 \&\& hasTicket;
```

Чтобы `canEnter` стало `true`:

* возраст должен быть ≥ 18;
* билет должен быть.

\---

# 45\. OR — `||`

Достаточно, чтобы хотя бы одно условие было истинным:

```ts
true || true   // true
true || false  // true
false || true  // true
false || false // false
```

Пример:

```ts
const isAdmin = false;
const isOwner = true;

const canEdit = isAdmin || isOwner;
```

Результат:

```text
true
```

\---

# 46\. NOT — `!`

Меняет boolean на противоположный:

```ts
!true  // false
!false // true
```

Пример:

```ts
const isLoggedIn = false;

console.log(!isLoggedIn); // true
```

\---

# 47\. Short-circuit evaluation

Это полезное дополнение к теме логических операторов.

JavaScript не всегда вычисляет выражение до конца.

## Для `\&\&`

```ts
A \&\& B
```

Если `A` уже `false`, результат точно будет `false`.

Поэтому `B` может вообще не вычисляться.

## Для `||`

```ts
A || B
```

Если `A` уже `true`, результат точно будет `true`.

Поэтому `B` может не вычисляться.

Это называется:

```text
short-circuit evaluation
```

или короткое замыкание вычислений.

Позже это очень часто встретится в реальном JavaScript/TypeScript-коде.

\---

# 48\. Приоритет `\&\&` и `||`

`\&\&` выполняется раньше `||`.

Например:

```ts
true || false \&\& false
```

сначала вычисляется:

```ts
false \&\& false
```

то есть:

```text
false
```

а затем:

```ts
true || false
```

получаем:

```text
true
```

Чтобы код было проще читать, лучше явно использовать скобки:

```ts
true || (false \&\& false)
```

или:

```ts
(true || false) \&\& false
```

Эти два выражения уже означают разное.

\---

# 49\. Truthy и falsy — полезно знать заранее

Это дополнительная концепция JavaScript, которая позже будет постоянно встречаться.

JavaScript может использовать не только `true` и `false` в логических выражениях.

Некоторые значения воспринимаются как `false`.

Их называют **falsy**:

```ts
false
0
""
null
undefined
NaN
```

Большинство остальных значений — **truthy**.

Например:

```ts
if ("hello") {
    console.log("Выполнится");
}
```

Строка `"hello"` — truthy.

Пока не нужно заучивать все детали. Просто знай, что логические операторы JavaScript работают не только с буквальными `true` и `false`.

\---

# 50\. `console.log()` как инструмент обучения и отладки

`console.log()` выводит значение:

```ts
const age = 18;

console.log(age);
```

Очень полезно выводить не только значение, но и подпись:

```ts
console.log("age:", age);
```

Если переменная меняется:

```ts
let score = 10;

console.log("Before:", score);

score += 5;

console.log("After:", score);
```

Так легче понять последовательность работы программы.

# 51\. Как читать ошибку TypeScript

Когда VS Code подчёркивает код красным, не стоит сразу просить AI исправить его.

Полезный алгоритм:

1. Навести курсор на подчёркнутую часть.
2. Прочитать сообщение TypeScript.
3. Определить:

   * какой тип ожидался;
   * какой тип получен;
   * в какой строке возникло несоответствие.
4. Попробовать сформулировать проблему своими словами.
5. Только затем исправлять.

Например:

```ts
let age: number = 18;

age = "twenty";
```

TypeScript скажет примерно:

```text
Type 'string' is not assignable to type 'number'.
```

Перевод:

> значение типа `string` нельзя присвоить переменной типа `number`.

Это гораздо полезнее, чем просто запоминать готовое исправление.

Не обязательно:

TypeScript сам выводит `number`.

# 53\. Как связаны все темы лекции

Вместо того чтобы учить их как отдельные правила, полезнее видеть цепочку:

```text
Данные
 ↓
храним в переменных
 ↓
у данных есть тип
 ↓
над значениями выполняем операции
 ↓
операции могут возвращать новые значения
 ↓
сравнения возвращают boolean
 ↓
boolean-условия объединяем через \&\&, ||, !
```

Например:

```ts
const age = 20;
const hasTicket = true;

const canEnter = age >= 18 \&\& hasTicket;

console.log(canEnter);
```

Разберём:

```ts
const age = 20;
```

→ переменная `age`, тип `number`.

```ts
age >= 18
```

→ сравнение, результат `boolean`.

```ts
const hasTicket = true;
```

→ переменная типа `boolean`.

```ts
age >= 18 \&\& hasTicket
```

→ логическая операция над двумя условиями.

Получаем:

```text
true
```

Это хороший пример того, как отдельные элементы языка начинают складываться в программу.

# 55\. Что действительно стоит запомнить после первой лекции

Не нужно пытаться запомнить каждую деталь языка.

На этом этапе важнее уверенно понимать следующее:

### 1\. Что делает переменная

```ts

```

### 2\. Когда `const`, а когда `let`

```text
const → не переназначаем
let → переназначаем
```

### 3\. Что такое тип

```text

18 → number
true → boolean
```

### 4\. Что `=` — присваивание

```ts

```

### 5\. Что `===` — сравнение

```ts
age === 18;
```

### 6\. Что TypeScript проверяет совместимость типов

```ts
let age: number = 18;

```

### 7\. Что оператор `+` зависит от типов

```ts
10 + 5    // 15

```

### 8\. Что `%` возвращает остаток

```ts

```

### 9\. Что сравнение даёт boolean

```ts

```

### 10\. Что условия можно объединять

```ts
conditionA \&\& conditionB
conditionA || conditionB
!condition
```
